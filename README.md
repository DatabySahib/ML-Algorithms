# Machine Learning & Data Science Portfolio

Welcome to my Machine Learning and Data Science repository! This repository serves as a comprehensive collection of the end-to-end projects I have developed. It showcases my journey in mastering machine learning algorithms, handling real-world datasets, and implementing structural data science workflows.

Each project follows a strict, structured roadmap: from rigorous Exploratory Data Analysis (EDA) and data cleaning to feature engineering, model implementation, and hyperparameter tuning.

##  Tech Stack & Tools
*   **Language:** Python
*   **Data Manipulation & Analysis:** Pandas, NumPy
*   **Data Visualization:** Matplotlib, Seaborn
*   **Machine Learning Library:** Scikit-Learn

---

##  Project Portfolio

### 1. Customer Segmentation (Unsupervised Learning)
*   **Algorithm:** K-Means Clustering
*   **Objective:** Segment customers based on purchasing behavior to optimize targeted marketing strategies.
*   **Key Highlights:** Applied the **Elbow Method** to identify the optimal number of clusters ($K=5$) and validated the clustering quality using the **Silhouette Score**.

### 2. Dimensionality Reduction on Medical Data
*   **Algorithm:** Principal Component Analysis (PCA)
*   **Dataset:** Breast Cancer Wisconsin (Diagnostic) Dataset
*   **Objective:** Reduce the dimensionality of a high-dimensional dataset while retaining maximum variance.
*   **Key Highlights:** Successfully compressed 30 numerical features into 2 principal components, enabling clear visual separation and variance analysis between diagnostic classes.

### 3. Loan Risk Prediction (Overfitting Mitigation)
*   **Algorithm:** Decision Tree Classifier
*   **Objective:** Predict loan default risks based on applicant profiles.
*   **Key Highlights:** Identified model overfitting by analyzing train/test accuracy gaps. Applied hyperparameter tuning (pruning techniques) to improve model generalization and robustness.

### 4. Water Potability Classification
*   **Algorithm:** Support Vector Machines (SVM)
*   **Objective:** Classify whether water is safe for human consumption based on its chemical properties.
*   **Key Highlights:** Conducted deep feature correlation analysis and utilized **Grid Search** to optimize SVM hyperparameters for maximum classification accuracy.

### 5. Customer Churn Prediction
*   **Algorithm:** K-Nearest Neighbors (KNN)
*   **Objective:** Predict customer churn for a subscription-based service.
*   **Key Highlights:** Utilized the **Elbow Method** to dynamically find the best $K$-value, and evaluated the model using detailed classification reports (Precision, Recall, F1-Score).

### 6. Bank Marketing Binary Classification
*   **Algorithm:** Logistic Regression
*   **Objective:** Predict whether a client will subscribe to a term deposit.
*   **Key Highlights:** Handled categorical variables using **One-Hot Encoding** and applied **Standard Scaling** to optimize the performance and convergence of the logistic model.

### 7. Car Price Prediction
*   **Algorithms:** Linear Regression & Random Forest Regressor
*   **Objective:** Estimate automobile prices based on technical specifications and market features.
*   **Key Highlights:** Conducted extensive outlier treatment during the EDA phase. Performed a model comparison using evaluation metrics such as $R^2$ and Mean Absolute Error (MAE).

### 8. Exploratory Data Analysis (EDA) & Cleaning Projects
*   **Hotel Booking Demand Dataset:** Investigated cancellation patterns and pricing trends. Focused heavily on advanced data cleaning, such as handling missing values in missing agent/company records.
*   **Netflix Dataset:** Cleaned and analyzed content trends, formatting messy text data, and visualizing insights over time.
